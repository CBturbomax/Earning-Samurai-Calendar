작업할 때마다 드는 토큰과 시간을 줄인다. `CLAUDE.md` 가 1,645줄이고 세션마다 통째로 읽히며,
고칠 때마다 사고 기록을 덧붙여 계속 길어지고 있다. 회원님 말: "내가 뭐 고쳐달라 하거나 뭐 읽어내는 데
시간이나 토큰이 불필요하게 낭비될까 봐."

- 옮긴 내용이 한 글자도 빠지지 않았다 — 옮기기 전 `CLAUDE.md` 의 모든 줄이 `CLAUDE.md` 또는
  `docs/notes/*.md` 어딘가에 그대로 있다(스크립트로 줄 단위 대조해 빠진 줄 0 을 확인하고 결과를 보고한다).
- `CLAUDE.md` 에 「이 주제를 건드리기 전에 이 파일을 읽을 것」 찾아가기 표가 있다.
- 되돌리기 안전망이 **작업 전에** 만들어져 있고, 되돌리기를 한 번 실제로 시험했다(아래).

## 방법

1. `CLAUDE.md` 에는 늘 필요한 것만 남긴다 — 작업 받는 규칙, 파이프라인 그림, 「손대는 위치」 표(축약),
   절대 규칙 한 줄씩(없는 숫자·시각을 지어내지 않는다 · 텔레그램 제외 업종 · Railway 는 `railway` 가지 ·
   수집 워크플로는 main 에서만 · `index.html` 은 직접 안 고친다 …), 워크플로별 담당 파일 표, 배포.
2. 나머지는 `docs/notes/` 아래 주제별 파일로 **문장을 고치지 않고 그대로** 옮긴다 —
   월매출 / 사업부·지역·수주 / 미국 공시(SEC·8-K) / 일본 공시(TDnet·JPX) / 홍콩 / 실시간 서버·텔레그램 /
   워크플로 운영 / 화면.
3. 찾아가기 표: 어떤 코드를 건드릴 때 어느 파일을 먼저 읽는지.
4. 앞으로의 규칙을 `CLAUDE.md` 에 적는다: 새 사고 기록은 주제 파일에 쓰고 `CLAUDE.md` 에는 한 줄만.
   `AGENTS.md` · `docs/AI_HANDOFF.md` 가 `CLAUDE.md` 의 절을 가리키는 데가 있으면 새 위치로 고친다.

## 되돌리기 안전망 (회원님 요청: "원래대로 해줘 하면 삭 돌리는 것, 다른 데 저장해 뒀다가")

작업을 시작하기 **전에** 둘 다 만든다.

- 원본 사본: `docs/backup/CLAUDE_2026-11-24.md` — 줄이기 직전의 `CLAUDE.md` 를 그대로 복사해 커밋한다
  (이 파일은 자동으로 읽히지 않으므로 토큰이 들지 않는다).
- 줄이기 직전 커밋: `1f1d50d`(2026-11-24) — 이 커밋의 `CLAUDE.md` 가 원본이다. (git 태그도 붙이려 했으나 이 세션은 태그를 올릴 권한이 없었다.)

회원님이 "설명서 원래대로 해줘"라고 하면:
`docs/backup/CLAUDE_2026-11-24.md` 를 `CLAUDE.md` 로 되돌려 놓고 `docs/notes/` 의 옮긴 파일을 지운 뒤 커밋한다.
그 사이 `CLAUDE.md` 에 새로 더해진 줄이 있으면 버리지 말고 되돌린 파일 끝에 붙인다.
다른 파일(코드·data)은 건드리지 않는다 — 수집 봇이 main 에 계속 커밋하므로 저장소 전체를 옛 커밋으로 돌리면 안 된다.
